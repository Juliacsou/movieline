Esta conexão está definida no código e vale para todos os jogadores. Não é necessário salvar ou configurar nada no navegador.

A chave privada permanece nos secrets do Cloudflare, nunca neste campo ou no GitHub.

Sem banco de filmes.

Títulos, anos e cartazes vêm do TMDB. O Worker faz a consulta e usa cache temporário; o navegador guarda apenas as preferências e a partida para retomada.

Esta versão não usa Supabase. Não crie tabelas nem execute o SQL da v1. Também não há upload de cartazes para R2 ou Supabase Storage.

Conexão externa: esta versão precisa do Worker movieline-tmdb atualizado no Cloudflare. O código do Worker é publicado separadamente do site; a chave privada permanece no Cloudflare.

Popularidade definida pela criadora, não pelo jogador: o padrão usa 1.000+ votos no TMDB, incluindo também os filmes com 3.000+ votos. A configuração fica em config.js. As páginas do catálogo são sorteadas.
